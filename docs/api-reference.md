# SIEM API Reference

## 1. Introduction

SIEM v1 provides a REST API built with FastAPI.

The API exposes stored security events, generated alerts, and activity statistics to the SOC dashboard.

The API acts as the communication layer between the SIEM backend and its presentation interface.

## 2. API Configuration

| Property | Value |
|---|---|
| Framework | FastAPI |
| API Title | Cyber Defense Platform API |
| Host | `127.0.0.1` |
| Port | `8000` |
| Protocol | HTTP |
| Data Format | JSON |

**Base URL:**

```text
http://127.0.0.1:8000
```

## 3. Available Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Returns API status |
| GET | `/events` | Retrieves recent security events |
| GET | `/alerts` | Retrieves recent security alerts |
| GET | `/statistics` | Retrieves event and alert statistics |
| GET | `/statistics/activity` | Retrieves hourly event activity |

## 4. Endpoint Details

### GET /

Returns the API status.

**Example request:**

```bash
curl http://127.0.0.1:8000/
```

### GET /events

Retrieves recent security events stored in the SQLite database.

**Example request:**

```bash
curl http://127.0.0.1:8000/events
```

Event records contain fields such as:

- Event ID
- Timestamp
- Hostname
- Process
- PID
- Severity
- Message
- Source

### GET /alerts

Retrieves recent alerts generated by the detection engine.

**Example request:**

```bash
curl http://127.0.0.1:8000/alerts
```

Alert records contain fields such as:

- Alert ID
- Event timestamp
- Alert timestamp
- Detection rule
- Severity
- Message
- Hostname
- Process
- Fingerprint

### GET /statistics

Retrieves event and alert statistics.

**Example request:**

```bash
curl http://127.0.0.1:8000/statistics
```

### GET /statistics/activity

Retrieves hourly event activity for the dashboard's 24-hour activity visualisation.

**Example request:**

```bash
curl http://127.0.0.1:8000/statistics/activity
```

## 5. API and Dashboard Communication

The SOC dashboard communicates with the FastAPI backend using HTTP requests.

```text
          SOC Dashboard
                 |
                 | HTTP GET
                 v
             FastAPI
                 |
                 v
          Database Module
                 |
                 v
            SQLite
                 |
                 v
          JSON Response
                 |
                 v
          SOC Dashboard
```

The dashboard uses API responses to display event records, security alerts, statistics, and activity information.

## 6. CORS Configuration

The current API configuration enables Cross-Origin Resource Sharing (CORS).

It allows all origins, methods, and headers, with credentials disabled.

This supports communication between the local dashboard development server and the API.

**Security consideration:** This permissive configuration is intended for local development. Production deployment should restrict allowed origins and review API access controls.

## 7. Running the API

Activate the project's virtual environment:

```bash
source .venv/bin/activate
```

Start the API:

```bash
python -m siem.api.api
```

The API is available at:

```text
http://127.0.0.1:8000
```

FastAPI also provides interactive API documentation at:

```text
http://127.0.0.1:8000/docs
```

## 8. Testing the API

The endpoints can be tested using `curl`.

For example:

```bash
curl http://127.0.0.1:8000/events
```

```bash
curl http://127.0.0.1:8000/alerts
```

```bash
curl http://127.0.0.1:8000/statistics
```

These requests allow the returned JSON data to be inspected directly.

## 9. Current Limitations and Future Improvements

Potential API improvements include:

- Authentication and authorisation.
- Pagination and configurable query limits.
- Filtering by severity, hostname, and detection rule.
- API input validation.
- Rate limiting.
- More detailed event investigation endpoints.
- HTTPS for deployment beyond localhost.

## 10. API Status

**Current status:** Core REST API implemented.

SIEM v1 exposes event retrieval, alert retrieval, event and alert statistics, and hourly activity data through FastAPI.
